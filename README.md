# Syed Ahad Ali: personal site

Source for [kagura-ahad.github.io](https://kagura-ahad.github.io/), built with [Hugo](https://gohugo.io/) and deployed to GitHub Pages with GitHub Actions.

## Credits

The theme is included unmodified in `themes/hugo-profile/` together with its original `LICENSE`. All site content (text, project descriptions, diagrams, photo) is my own, in `hugo.yaml`, `layouts/` and `static/`.

## Run locally

Requires Hugo extended 0.168.0 or newer.

```
hugo server
```

Then open http://localhost:1313/.

## Editing the projects page

Every project lives under `params.projects.items` in `hugo.yaml`. The home cards use its `tagline` and `headline`; the detailed page at `/projects/` uses the rest.

- **Diagrams** are plain HTML and CSS, described by a `flow:` block per project (rows, zones, steps, connectors). They are rendered by `layouts/partials/flow.html`, styled by `static/flow.css`, and the connector lines are drawn by `static/flow.js`.
- **GraphRAG pyramid** (DocsKeeping): the `graphrag:` block plus `layouts/partials/graphrag-svg.html`, which is generated by `python3 scripts/graphrag_pyramid.py`.
- **Notes-style entries** (Learning TensorRT 11) use a `notes:` block instead of a diagram.
- Diagrams deliberately use the opposite colours to the page theme, so they stand out in both light and dark mode. The colours are in `static/flow.css`.

No extra tools are needed: the site is plain Hugo.

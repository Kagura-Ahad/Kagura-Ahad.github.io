# Syed Ahad Ali: personal site

Source for [kagura-ahad.github.io](https://kagura-ahad.github.io/), built with [Hugo](https://gohugo.io/) and deployed to GitHub Pages with GitHub Actions.

## Credits

This site uses the [**Hugo Profile**](https://github.com/gurusabarish/hugo-profile) theme by [Gurusabarish](https://github.com/gurusabarish), released under the MIT License. The theme is included unmodified in `themes/hugo-profile/` together with its original `LICENSE`. All site content (text, project descriptions, photo, project card images) is my own, in `hugo.yaml` and `static/`.

## Run locally

Requires Hugo extended 0.168.0 or newer.

```
hugo server
```

Then open http://localhost:1313/.
